# MiteMapTools: A toolkit for analyzing arthropod movement data

MiteMapTools provides a comprehensive suite of functions for importing,
processing, and analyzing movement data from MiteMap tracking systems.
MiteMap is a Raspberry Pi-based automated tracking system designed to
monitor arthropod behavior in controlled 2D arenas.

## Background

The MiteMap system consists of a circular arena (typically 40mm
diameter) where arthropods are tracked using infrared imaging. The arena
can be configured with attractive or repulsive stimuli (e.g., volatile
compounds) to study chemotactic behavior. Position data is recorded at
high temporal resolution (every 0.2 seconds).
